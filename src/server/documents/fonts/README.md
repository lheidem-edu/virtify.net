# Inter

Static instances of [Inter](https://rsms.me/inter/) at 400 / 500 / 600, fetched
from Google Fonts (`fonts.gstatic.com`, Inter v20). They are embedded into every
PDF we generate so documents read in the same typeface as the website; see
`../typography.ts`.
